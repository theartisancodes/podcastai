# PodcastAi 🎙️

PodcastAi is an AI-powered podcast generation app that converts text into natural-sounding speech. Effortlessly create, manage, and publish AI-generated podcasts with an intuitive UI built with **Next.js, Tailwind CSS, and TypeScript**.

## 🚀 Features

- 🔊 **AI Text-to-Speech** – Generate high-quality voiceovers using OpenAI's API.
- 🎙 **Podcast Management** – Organize, edit, and publish episodes easily.
- 🏗 **Modern Tech Stack** – Built with Next.js 15, Tailwind CSS, and React 19.
- 🔐 **User Authentication** – Powered by Clerk authentication.
- 📦 **Cloud Storage** – Upload and manage podcast files with Convex.
- 🎨 **Customizable UI** – Responsive and beautiful UI using Radix UI components.
- 📈 **Progress Tracking** – Visualize playback with progress indicators.
- 📲 **Web & Mobile Friendly** – Optimized for all devices.

## 🛠 Tech Stack

- **Frontend:** Next.js 15, React 19, Tailwind CSS, Radix UI
- **State Management:** React Hook Form, Zod
- **Authentication:** Clerk
- **Storage & Backend:** Convex, UploadStuff, Svix
- **Linting & Formatting:** ESLint, Prettier
- **AI Integration:** OpenAI API

## 📦 Installation

Clone the repository:

```sh
git clone https://github.com/theartisancodes/podcastai.git
cd podcastAi
```

Install dependencies:

```sh
yarn install  # or npm install
```

## 💻 Development

Run the app locally:

```sh
yarn dev  # or npm run dev
```

## 🚀 Production Build

Build the app for production:

```sh
yarn build  # or npm run build
yarn start  # or npm start
```

## 🔍 Linting & Formatting

Ensure code consistency:

```sh
yarn lint  # or npm run lint
```
